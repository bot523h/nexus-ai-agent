feat(llm): W2 Global LLM Gateway Authority — one path to a model

Builds the single authority every LLM call now passes through, replaces the
six duplicated call paths with one contract + one policy surface, and proves
it with structure, behaviour and mutation testing.

Architecture: Caller -> facade/registry -> engine.execute(LLMRequest)
  -> policy.plan (routes, budget, retry, fallback, privacy, idempotency)
  -> scheduler (global/provider/tenant bulkheads, bounded queue)
  -> rate gate (minute + UTC-day windows, Retry-After, quota exhaustion)
  -> circuit breaker -> adapters (Gemini REST / litellm Router / legacy)
  -> usage (provider-reported only) -> observability (one record per request)

New: src/nexus_ai_agent/llm/gateway/{contract,policy,resilience,scheduler,
adapters,usage,observability,engine,registry,facade,__init__}.py, extended
src/nexus_ai_agent/llm/errors.py (18 typed kinds; retryable and
fallback-eligible derived from the kind).

Migrated callers: features/ai_chat.py, features/summarizer.py
(allow_fallback=False), features/ai_memory.py, agents/store/base_agent.py,
creative/video_director.py, llm/gemini_provider.py, llm/litellm_provider.py
(Router becomes one adapter, max_attempts=1 so no retry nests inside the
chain), llm/local_server_provider.py + llm/local_llama_cpp.py (wrapped by
LegacyProviderAdapter), llm/fallback_provider.py (hops on typed
fallback_eligible; substring error_keywords deprecated and empty by default).
The pre-W2 generate/complete/embed surface and the user-facing failure strings
are preserved byte-for-byte.

Guards:
- substring classification is banned structurally: tests/architecture/
  test_llm_gateway_authority.py walks every file in src/ and fails on
  "<error keyword>" in str(...). Current findings: 0 in 259 source files,
  with a liveness test so the gate cannot pass because the detector broke.
- the caller inventory is a two-way ratchet: an undocumented path to a
  provider fails, and a stale permission fails too.
- pinned bypasses: 2 (creative/image_gen/gemini_adapter.py image generation;
  creative/slideshow/analysis.py synchronous vision scoring). Both named,
  justified, typed, and forbidden from growing (MAX_PINNED_BYPASSES = 2).

Evidence (Python 3.11.2, full dependency set):
- pytest tests/architecture/test_llm_gateway_authority.py -> 12 passed
- pytest tests/unit -k llm_gateway -> 637 passed, 1 skipped (13 files)
- python scripts/llm_gateway_mutations.py -> 49/49 mutants killed,
  baseline GREEN before and restored copy GREEN after
- pytest -q -rs -m "not slow" -> 3564 passed, 31 skipped, 0 failed
  (baseline 2915/30; delta +650 = 638 gateway + 12 architecture tests)
- ruff check / ruff format --check / mypy src -> clean (259 files)

22 real defects in the authority were found by this programme and fixed,
including a backoff that could sleep past the caller's deadline, a late answer
returned after the budget expired, a rate-limit refusal mislabelled as a
deadline, throttled refusals not counted in status(), degraded answers not
flagged, str(error) reaching a record, and a queue waiter stranded beside
idle capacity.
