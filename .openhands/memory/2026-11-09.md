## Durable lessons
- **`GITHUB_TOKEN` in this env has NO push access to `bot523h/nexus-ai-agent`**
  (403). `git remote` has NO credential helper and prompts. Push with
  `git push "https://x-access-token:${GITHUB_PERSONAL_ACCESS_TOKEN}@github.com/bot523h/nexus-ai-agent.git" <branch>`.
- **Never run the mutation campaign concurrently with the test suite**: the
  campaign mutates source in place, so an anchor-integrity test
  (`test_durable_project_state_anchors_occur_exactly_once`) can read a mutated
  file and report a spurious `0` count. Run them serially.
- **`.venv/bin/python -m pytest tests/unit/test_pg_integration_safety.py`** is the
  guard for the PG destructive opt-in; it runs on `pythonpath = ["."]` (pytest
  rootdir inserts repo root), so `from tests.unit.test_pg_integration_safety import ...`
  works.
- **A behavioral test double must model the real API**: `get_session` is a
  plain function returning an `AsyncSession` context manager; wrapping it needs
  `self._ctx = factory(); self._session = await self._ctx.__aenter__()` — a
  naive `await factory().__aenter__()` stored the CM, not the session.
- **`_reap` draining via `communicate()` closes the pipes** → read stderr from
  `_reap`'s return value, never `proc.stderr.read()` afterward (ValueError).
