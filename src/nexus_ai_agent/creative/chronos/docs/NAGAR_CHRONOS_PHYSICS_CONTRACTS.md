# Nagar Chronos physics contracts

Chronos is a deterministic CPU kernel layer: it performs no network access and uses SI seconds/meters unless a parameter explicitly says mm, pixels, samples, or ticks. Integer PTS plus a positive `Fraction` time base is authoritative; conversion to another clock is allowed only when exact. Floating-point wall-clock accumulation is forbidden.

## Kernel and units

* **Timeline:** `RationalTimestamp.pts` is integer ticks; `time_base` is seconds/tick. `concat_copy` probes, checks signatures and packets, full-decodes and boundary-decodes staged media, checks packet counts and duration within 1 ms, then hashes and atomically publishes. `assemble_pcm_wav_stream_copy` concatenates raw PCM frames with stdlib `wave`; its separate on-disk verifier proves exact frame and payload-byte conservation, exact `Fraction(nframes, sample_rate)` duration, splice boundary sample readability, and post-publish hash. Both receipts use `NO_ADDITIONAL_REENCODE_LOSS_AT_ASSEMBLY`; this is an assembly-mode claim, not perceptual quality.
* **Geometry:** world coordinates are meters, optics are mm, sensor dimensions mm, image coordinates pixels. `WorldScaleReceipt` labels invariant height as `WORLD_SPACE_CHARACTER_SCALE` and projected pixel height as `IMAGE_SPACE_PROJECTED_SCALE`. `K[R|t]P` requires SO(3) and positive camera depth. Brown–Conrady coefficients are `(k1,k2,k3,p1,p2)`; `undistort_normalized_point` iteratively inverts them and reports residual. `backproject_character_height_m` reports recovered scale and pixel-derived Type-A sensitivity. Thin-lens CoC returns pixels; the centered-height depth Jacobian is analytical.
* **Color:** sRGB and BT.709 have piecewise encode/decode functions. `cct_kelvin_to_xyz` uses the standard cubic Planckian-locus approximation for CIE xy from 2000–15000 K (not a daylight-locus model), then normalizes Y to 1. Bradford adaptation accepts caller-provided XYZ whites. `match_linear_rgb_gaussian_ot` transports full RGB Gaussian means/covariances with symmetric `eigh` matrix powers and epsilon regularization; `preserve_structure` is a scalar log-luminance variance transform. PNG verification independently reloads filter-zero RGB8 bytes, checks CIEDE2000 convergence, and enforces Sobel-gradient correlation >= 0.985.
* **Acoustics:** coordinates/dimensions are meters, speed is 343 m/s, delays are fractional samples. The shoebox image-source model uses distance attenuation and absorption power; `synthesize_stereo_room_ir` reports geometric DRR and theoretical Sabine RT60, with optional measured fields where the Schroeder fit succeeds. `measure_rir_acoustics` measures direct/reverberant energy and backward-integrated Schroeder decay (T20/T30 range selection). Sabine/Eyring remains theoretical. Timbre comparison is `ACOUSTIC_TIMBRE_CONSISTENCY`, never biometric ID. Jaw peak lag is a discrete sample-index measure from `solve_jaw_trajectory`; it is not guaranteed below half a frame for arbitrary drives.
* **Jaw:** inputs are ordered rational timestamps and normalized aperture targets. The solver integrates the critically damped second-order model with deterministic bounded substeps.

## Ground-truth error and uncertainty matrix

| Quantity | Reference | Error/uncertainty contract |
|---|---|---|
| rational time | exact Fraction | zero quantization unless rescale is unrepresentable, then fail |
| pinhole pixel | analytic K[R|t] | floating-point matrix error; propagate depth sigma with `abs(dH/dZ) sigma_Z` |
| CoC | thin-lens equation | input uncertainty in f, N, focus, subject distance, and pixel pitch must be propagated by caller |
| RT60 | Sabine/Eyring | model uncertainty dominates; not calibrated without measured decay |
| RIR | image-source model | finite reflection order and fractional-sinc truncation bound accuracy |
| color | transfer/adaptation equations | clipping and display encoding are not scene-linear operations |
| structural check | gradient correlation | not a semantic identity metric; threshold is a postcondition only |

## CommandBus integration handoff

`ChronosPort.execute` / `execute_chronos_command` accepts immutable `ChronosCommand` with operation, ordered input references, string parameters, deterministic=true, external_api_allowed=false. It invokes an explicitly injected `ChronosHandler`, validates the returned operation and nonempty SHA-256, and rejects UNKNOWN continuity. The allowlist and `creative.chronos.build_default_chronos_handlers()` currently contain matching concrete adapter names for all 31 Studio operations spanning timeline, geometry, color, acoustics, audio, identity, compositing, scene, Merkle, motion, temporal optics, weather/grading, and episode continuity. `test_all_default_handler_names_are_registered_and_dispatchable` audits set equality and dispatches every operation through the pure Studio port using a receipt spy; it proves registry completeness and dispatch routing, not the behavior of every adapter's external-file input format. Inputs, authorization, cancellation, resource limits, and AssetVersion passports remain caller responsibilities.

## Wave-2 research prototypes (not production guarantees)

Wave-2 adapters are registered by `build_default_chronos_handlers()` and accepted by the pure Studio port for six Wave-1 plus twelve Wave-2 operation identifiers. WAV de-click, duck, pose, eyeline, compositor, scene operations, and Merkle handlers serialize via local files; inputs are caller-supplied paths/NPY/NPZ/JSON as described by each command's parameters. The compositor evaluates halo-expanded tiles and returns estimated NumPy working-buffer bytes, full-frame-equivalent bytes, working-memory reduction ratio, and the separate RGB8 output-buffer byte count; the estimate omits allocator overhead and caller-owned input arrays. Its RGB extinction coefficients apply per-channel Beer-Lambert attenuation; channel ordering is not enforced. Identity fitting retains six Huber IRLS passes and now computes a per-landmark 3x3 GUM covariance from analytical pinhole/Brown-Conrady Jacobians and pixel/depth uncertainties; `sigma_mm` remains a legacy compatibility parameter and does not enter this covariance. Eyeline receipts retain point-to-ray acceptance checks and additionally report exact 3D line closest-approach distance with a parallel-line fallback. Inpainting now performs coupled harmonic/biharmonic SOR updates and reports Dirichlet energies plus the masked biharmonic residual; the filmic curve exposes minimum/maximum density, contrast gamma, and halation controls. These remain CPU research kernels: H&D-like tonemapping is not a measured silver-halide response, and mathematical residuals do not establish perceptual quality. Real-disk verification covers WAV/PNG and local NumPy serialization; numerical equation checks are REAL-COMPUTE; FFmpeg/ffprobe integration remains SUBPROCESS-MOCK in this environment. Calibrated optical/sensor uncertainty and measured photochemical response remain outside the verified scope.

## Wave-4 biomechanics and shutter kernels

`biomechanics_motion.py` adds `motion.solve_ik`, `motion.foot_lock`, `motion.verlet_chain`, and `motion.shutter_blur` to the injected deterministic handler map and the pure Studio operation allowlist. IK uses planar forward kinematics in a target-aligned 3D plane and damped least-squares updates `Jᵀ(JJᵀ+λ²I)⁻¹e`; unreachable targets beyond summed bone lengths fail unless explicit clamping is enabled, in which case the receipt reports the residual. Joint bounds are relative-angle bounds. Foot-lock input is rational-timestamped 3D ankle data; horizontal XY coordinates are fixed during contiguous contact frames and cubic smoothstep ramps are applied on adjacent swing samples. The receipt reports pre-lock and post-lock horizontal slip in millimeters; zero post-lock slip is asserted only between consecutive stance frames. Secondary chains use position-Verlet prediction with gravity, wind acceleration, drag and positional distance constraints; an anchored forward projection enforces segment lengths, and the measured strain receipt is computed from the generated coordinates. This is a point-chain solver, not a full rigid-body or material model. Shutter blur averages sub-frame scene-linear samples for `angle/360` exposure using periodic bilinear boundaries; periodic sampling makes summed radiance conserved, while edge wrapping is an explicit image-boundary assumption, not a crop-free camera model. The operation adapters use local NPY/NPZ inputs and persisted receipts. Numerical guarantees are REAL-COMPUTE; output-file hashes are REAL-DISK; this does not imply performance or perceptual equivalence to a production character, cloth, or camera renderer.

## Wave-5 temporal optics kernels

`temporal_optics.py` registers `temporal.phase_corr`, `temporal.deflicker`, and `temporal.rectify_rolling`. Phase correlation mean-centers and Hann-windows both grayscale/RGB inputs, uses normalized cross-power `F(a) conj(F(b))/(|.|+ε)`, applies a three-point peak parabola, then refines its seed with a weighted unaliased central phase-plane fit; tested Fourier-shift fixtures recover subpixel translations to better than 0.05 px. Deflicker measures the frame log-luminance median, applies a symmetric zero-phase Gaussian kernel, and radiometrically scales each frame; its reported variance is the variance of first differences of the log-luminance trajectory, not total sequence variance. The target flag is empirical per receipt; a quiet input has zero variance and is treated as already stable. Rolling-shutter correction performs row-dependent inverse bilinear sampling for both axes, clamps samples at image edges, and reports maximum warp and readout/frame ratio. These are REAL-COMPUTE kernels; adapter array I/O is REAL-DISK. The FFT tracker assumes one global translation and the rolling-shutter model assumes constant angular image velocity during readout; neither models rolling geometric deformation, occlusion, lens distortion, or nonrigid scene motion.

## Wave-6 weather optics and grading kernels

`weather_and_grading.py` registers precipitation rendering, `grading.apply_cdl_lut`, `grading.serialize_cube`, and `grading.legalize_ebu_r103`. Particle exposure is `t = (θ/360)/fps`; the receipt reports vertical streak length `fy * v_terminal * t / Z`, wind-adjusted total length, deterministic particle count, and Beer–Lambert transmission `exp(-κZ)`. Streaks are sampled and bilinearly splatted into an RGB scene-linear array; this is a deterministic point-particle renderer, not a calibrated weather radiance model. ASC-CDL follows `max(0, RGB*slope + offset)^power`, Rec.709-luma saturation, then optional trilinear interpolation of a parsed/serialized red-fastest `.cube` lattice. An identity lattice is verified by reconstruction error under `1e-7`; LUT inputs outside their domain clamp to the edge lattice. The EBU-R103-named legalizer detects any RGB channel outside `[0,1]`, remaps the observed luminance range affinely when luma itself is illegal, then performs soft chroma compression toward legal luminance and clips floating-point roundoff. Its receipt reports illegal-pixel fractions and Sobel-component correlation. This lightweight legalizer is a hue-directed gamut compression approximation, not a complete EBU R103 signal-chain conformance analyzer (no legal-range code-value, Y′CbCr, transfer-function, or metadata checks). Grading math is REAL-COMPUTE; precip/grade/quality receipts are persisted REAL-DISK; all operations are offline CPU implementations.

## Wave-7 episode continuity and mastering pipeline

`episode_pipeline.py` adds immutable `ShowBibleCharacterBible`, per-episode/shot observations, typed `ContinuityRefusal`, and a transitive delta-invalidating `ShotDAG`. The canonical registry compares 3D landmark RMS, metric height, cepstral-envelope RMS, and Euclidean CIE LAB distance against explicit thresholds. `run_verified_episode_continuity_pipeline` fails closed on UNKNOWN/FAIL DAG state, local hash mismatch, identity/GUM residual, cross-lens back-projected height drift, 180-degree/skew-ray failure, unreachable IK, or stance slip. It grades scene-linear RGB through the shared CDL/LUT and broadcast legalizer, renders and reloads tiled RGB8 PNGs, makes camera-oriented stereo image-source room IRs, checks cepstral timbre, derives jaw-drive envelopes from the actual PCM dialogue, sidechain-ducks on-disk ambience, stream-copies the rendered PCM WAV segments, applies sample-count-preserving splice smoothing, and persists SHA-256s and RFC 6962 inclusion proofs. WAV inputs are constrained to uncompressed mono PCM16 at matching rates; rendered assembly output is stereo PCM16. The staging pipeline performs real computation and real disk I/O; the show-bible envelopes and skin LAB values are caller-supplied evidence, not extracted biometric truth, and thresholds are engineering contracts rather than validated clinical/perceptual thresholds. The JSON Studio adapter uses local manifest paths only; no network APIs are invoked. `EpisodeContinuityPassport.all_invariants_verified` means the enumerated code checks and disk/hash verifications completed—not a claim of production readiness or universal continuity.

## Wave-10 season continuity evidence

`test_twelve_episode_season_continuity_is_show_bible_anchored_and_merkle_persisted` constructs 12 episodes by 10 shots (120 total) against one immutable Show-Bible record and verifies all 120 observations through `verify_cross_episode_show_bible`. It contrasts this anchored control with a deliberately naive recurrence: a 0.02% cranial-scale increase per shot, 0.025 LAB-L units added per shot, and per-shot rounding of a 44.1 kHz / 24 fps interval (1837.5 samples). The deterministic fixture's naive control accumulates nonzero scale/color drift and 60 sample-clock samples; Chronos instead derives each boundary from the absolute rational frame timestamp, preserving exactly zero integer sample-clock drift over the season. The anchored cranial baseline is required to remain below `1e-9` relative drift, and each shot's LAB Euclidean delta-E must remain at or below 2.0. The test builds 120 canonical receipt leaves, checks an inclusion proof for every leaf, and persists the canonical manifest and SHA-256 Merkle root via `WorkspaceFilesystem`; a second independently persisted run must produce identical receipts and root. The checked root is `a6dd549235928acccd271c6d8b4606b5388c39afd31a2c267fb4f9df0d8b2a16`; the deterministic fixture reports 60 naive sample-clock samples, 0 anchored samples, 0.024287859924529087 maximum naive relative cranial-scale drift, and 2.9999999999998295 maximum naive LAB delta-E, versus zero anchored scale and color drift. This is deterministic synthetic continuity evidence exercising the named contracts, not a measurement of production footage, biometric identity, perceptual color, or captured dialogue.
