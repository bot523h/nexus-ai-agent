# 🎬 Film Studio — ساخت سریال به شکل «سینمایی صوتی‌تصویری»

این پوشه موتور ساخت فیلم است: تصاویر صحنه‌ها + حرکت آرام دوربین + نریشن/دیالوگ + موسیقی
→ خروجی **MP4 (H.264/AAC)** آمادهٔ آپلود در گوگل درایو.

> ⚠️ صادقانه: این موتور ویدیوی حرکتی واقعی (بازیگر متحرک) تولید نمی‌کند؛
> تصاویر ثابت با پن/زوم سینمایی و صداگذاری به یک فیلم کوتاه تبدیل می‌شوند
> (سبک animatic / motion-comic).

## ساختار پوشه‌ها

```
film_studio/
├── build_episode.py          # موتور رندر
├── README.md
└── series/<نام-سریال>/
    ├── bible.md              # دنیا، قواعد، لحن، پیوستگی داستان
    ├── characters/
    │   ├── <شخصیت>.md        # «کارت شخصیت»: سن، چهره، لباس، صدا، انگیزه
    │   └── refs/<شخصیت>.png  # تصویر مرجع چهره (رفرنس همهٔ صحنه‌ها)
    └── ep01/
        ├── manifest.json     # نقشهٔ اپیزود
        ├── scenes/01.png …   # تصاویر صحنه‌ها
        ├── audio/01_ravi.mp3 # کلیپ‌های صدا
        └── ep01.mp4          # خروجی نهایی (+ ep01.srt)
```

## چطور یک اپیزود رندر می‌شود

```bash
FF=$(/home/user/.venv/bin/python -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())")
FFMPEG_BIN="$FF" python3 film_studio/build_episode.py \
    film_studio/series/<نام>/ep01/manifest.json \
    --out film_studio/series/<نام>/ep01/ep01.mp4
```

## فرمت `manifest.json`

```json
{
  "title": "قسمت اول — عنوان",
  "width": 1920, "height": 1080, "fps": 30,
  "crossfade": 0.6,
  "fade_in": 0.8, "fade_out": 1.2,
  "music": "audio/bed.mp3",
  "music_gain_db": -22,
  "scenes": [
    {
      "image": "scenes/01.png",
      "duration": 7.0,
      "motion": "zoom_in",
      "audio": [
        {"file": "audio/01_sara.mp3", "offset": 0.6, "gain_db": 0},
        {"file": "audio/02_amir.mp3", "offset": 4.2, "gain_db": -2}
      ]
    }
  ],
  "subtitles": [
    {"start": 0.6, "end": 3.4, "text": "سارا: اینجا هیچ‌وقت این‌قدر ساکت نبود."}
  ]
}
```

- `motion`: `zoom_in` | `zoom_out` | `pan_left` | `pan_right` | `pan_up` | `pan_down` | `still`
- `duration`: مدت صحنه به ثانیه (۴ تا ۹ ثانیه برای هر تصویر خوب است)
- `audio[].offset`: فاصله از شروع **همان صحنه** تا پخش آن کلیپ
- اگر مانیفست `subtitles` داشته باشد، فایل `.srt` کنار ویدیو ساخته می‌شود.

## قواعد ثبات شخصیت‌ها (مهم)

1. برای هر شخصیت **یک تصویر مرجع** در `characters/refs/` ساخته می‌شود (پرتره، نور خنثی، تمام‌رخ).
2. همهٔ تصاویر صحنه‌های بعدی با همان فایل به‌عنوان **رفرنس ورودی** تولید می‌شوند
   → چهره/لباس/سن بین صحنه‌ها و اپیزودها تغییر نمی‌کند.
3. هر تغییر ظاهری (زخم، بارانی خیس، لباس جدید) در `characters/<نام>.md` **ثبت** می‌شود
   تا در اپیزودهای بعد هم درست بازتولید شود.
4. هر شخصیت یک `voice_id` ثابت دارد؛ کل دیالوگ‌هایش در تمام سریال با همان صدا ساخته می‌شود.
5. `bible.md` حافظهٔ سریال است: هر اتفاق مهم اپیزود همین‌جا نوشته می‌شود تا قصه از هم نپاشد.

## محدودیت‌های هر نوبت

- حداکثر **۱۰ کلیپ صوتی** و چند تصویر در هر نوبت → اپیزود ۵ دقیقه‌ای در ۲–۳ نوبت کامل می‌شود.
- رندر ویدیو در سندباکس انجام می‌شود و فقط خروجی MP4 + SRT در گوگل درایو آپلود می‌شود.
